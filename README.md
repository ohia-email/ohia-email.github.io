# Ohia public website

Public product information, privacy policy, data controls, terms, and support for Ohia, a native macOS email client developed by Jason G. Karlin.

**Website:** https://ohia-email.github.io/

This repository contains the homepage (HTML), the Markdown documents, two layouts in `_layouts/` with shared chrome in `_includes/`, one stylesheet (`assets/css/site.css`), and GitHub Pages configuration only. No theme gem and no third-party assets. Ohia's application source code, account configuration, and private development materials are not included.

- [Homepage](index.html) (`home` layout)
- [Privacy Policy](privacy.md)
- [Manage and delete your data](data-controls.md)
- [Terms of Use](terms.md)
- [Support](support.md)

Content can be edited directly on GitHub. GitHub Pages publishes the `main` branch with Jekyll; no application build is needed.
